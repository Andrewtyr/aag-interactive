# Скрипты проекта

- `start-lan.mjs` — локальный запуск с адресом для устройств в одной сети.
- `package-server.ps1` — собирает архив исходников для VPS без локальных данных и паролей.
- `load-test.mjs` — нагрузочная проверка на отдельной тестовой базе.
- `build-public-preview.mjs` — обновляет безопасный публичный образец презентации.
- `export-pptx.ps1` — экспорт страниц PowerPoint для импорта в редактор.

Главная инструкция публикации: [SERVER-SETUP.md](../SERVER-SETUP.md).
